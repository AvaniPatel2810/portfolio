# Avani Patel — Portfolio

A single-page personal portfolio built with React + Vite. Features smooth animations via Framer Motion, sections for About, Experience, Projects, Skills, and Contact, and a downloadable resume.

## Stack

- **React 19** + **Vite 8**
- **Framer Motion** for animations
- **react-icons** for icon sets
- No backend — fully static

## Running the app

```bash
npm run dev
```

Runs on port 5000. The "Start application" workflow handles this automatically in Replit.

## Project structure

```
src/
  App.jsx      # All portfolio content and components
  App.css      # All styles
  main.jsx     # React entry point
public/
  AvaniPatel.pdf  # Resume (served at /AvaniPatel.pdf)
```

## User preferences

- Keep the existing project structure — single App.jsx + App.css pattern.
