# Avani Patel 

A modern, responsive, and interactive personal portfolio developed using **React**, **TypeScript**, **Vite**, and **Tailwind CSS**. This portfolio showcases my technical skills, projects, internship experience, and provides an overview of my journey as a Computer Engineering student passionate about Full-Stack Development and Artificial Intelligence.

## Getting Started

### Clone the repository

```bash
git clone https://github.com/AvaniPatel2810/portfolio.git
```

### Navigate to the project

```bash
cd portfolio
```

### Install dependencies

```bash
npm install
```

### Start the development server

```bash
npm run dev
```

### Build for production

```bash
npm run build
```
